# 场地查重、去重与批量导入说明

## 一、本次已完成的改动

### 后端（NestJS，`Server/api`）
1. **提交自动查重**：`createVenue` 入库前先比对（`src/modules/venues/venues.service.ts`）
   - 同运动类型 + 规范化名称相同 → 判定重复，拦截并返回已有场地信息；
   - 名称不同但规范化地址相同 → 判定重复；
   - 坐标距离 < 80m 且名称含相同关键字 → 辅助提示（现有数据多为占位坐标，仅作弱匹配）。
   - 查重失败不会阻断正常录入。
2. **查重接口**（`venues.controller.ts`）
   - `POST /venues/check-duplicate`：传入 name/address/sportType，返回 `{ isDuplicate, duplicate }`；
   - `GET /venues/duplicates`：管理端用，返回疑似重复分组（同名 / 同地址）。
3. **批量导入脚本**：`src/add-venue-bulk.ts`（命令 `npm run add-venue:bulk`）
   - 内置 CSV 解析（支持双引号转义），全字段映射；
   - 入库前自动查重（库内同名 / 库内同地址 / 文件内重复）并跳过；
   - 字段校验（sportType、cityCode、坐标合法性）；
   - 支持 `--dry-run` 只出校验报告不写库。

### 前端（Next.js，`Web/webapp`）
1. **查重去重页**：`/admin/duplicates`
   - 按同名 / 同地址分组展示，可按篮球 / 足球筛选；
   - 每条可跳转编辑、删除（仅管理员），刷新重新拉取。
2. **添加页实时查重**：`/admin/add-venue`
   - 名称 / 地址输入防抖 600ms 自动比对，命中重复即红色提示已有场地；
   - 提交时后端再次拦截，重复不会写入。
3. **前端代理路由**：`src/app/api/venues/duplicates`、`src/app/api/venues/check-duplicate`。
4. **CSV 模板**：`data/venues-template.csv`。

## 二、运行与验证

- 本地后端：`cd Server/api && npm run dev`（端口 4000，连 `.env` 中的 `DATABASE_URL`）
- 本地前端：`cd Web/webapp && npm run dev`（端口 3000）
- 批量导入预览：`npm run add-venue:bulk -- <csv路径> --dry-run`
- 正式入库：去掉 `--dry-run`

> 注意：`.env.local` 的 `NEXT_PUBLIC_API_BASE` 当前指向线上 Railway。后端新接口需**重新部署后端**后，线上前端代理才能访问；本地联调可临时改为 `http://localhost:4000`。

## 三、当前状态（批量真实入库前需确认）

1. **地理编码 Key：已解决** ✅
   - 高德「Web 服务」Key 已配置到后端 `.env` 的 `AMAP_WEB_KEY`（已被 git 忽略，不进前端）。
   - 工具模块：`Server/api/src/lib/geocode.ts`；导入脚本在坐标缺失时自动按地址解析经纬度，解析不到则跳过并记录。
   - 已实测：北京、杭州地址均可返回准确坐标。

2. **综合场馆的运动类型口径：待确认**
   - 官方名录多为"体育中心/文体中心"，同时含篮球、足球、游泳、羽毛球等。
   - 需确定：含篮球建一条 `basketball`、含足球再建一条 `football`；还是只录入明确单一球类的商业球馆。

3. **数据来源**
   - 公共场馆：政府体育局名录，权威但类型混合、价格多为空（坐标已可由地理编码补齐）。
   - 商业球馆：活动网 / 电话邦等，类型较明确、有电话与价格区间。

## 四、字段对照（导入 CSV 列）

必需：`name, sportType(basketball|football), cityCode, lng, lat`
可选：`districtCode, address, priceMin, priceMax, priceDisplay, supportsWalkIn, walkInPriceDisplay, supportsFullCourt, fullCourtPriceDisplay, indoor, contact, requiresReservation, reservationMethod, isPublic, courtCount, floorType, playersPerSide, openHours, hasLighting, hasAirConditioning, hasParking, hasFence, hasRestArea, hasShower, hasLocker, hasShop`

城市代码示例：北京 110000、天津 120000、上海 310000、重庆 500000、广州 440100、深圳 440300、杭州 330100、南京 320100、成都 510100、武汉 420100。

## 五、已采集的首批公开线索（待口径确认后结构化入库）

- **北京**：北京市体育局《向市民开放公共体育场馆数据》33 条（名称/区/地址/电话），含地坛体育中心、朝阳体育中心、丰台体育中心、顺义体育中心（仅室外篮球场）等。来源：tyj.beijing.gov.cn
- **杭州**：杭州市体育局《大中型体育场馆名录》30 条（名称/项目/地址），含江南体育中心、滨江区体育馆（篮球+笼式足球）、丁兰文体中心（篮球馆+五人制足球场）等。来源：ty.hangzhou.gov.cn
- **商业球馆线索**：活动网 / 电话邦等渠道的杭州、成都、北京篮球馆/足球场，含名称、区县、地址、电话、参考价格区间与开放时间。

以上线索**均缺经纬度**，且公共场馆为综合项目，需先确定分类口径、补地图 Key 后再结构化并查重入库。
