# 场地查重、去重与批量导入说明

## 一、本次已完成的改动

### 后端（NestJS，`Server/api`）
1. **提交自动查重**：`createVenue` 入库前先比对（`src/modules/venues/venues.service.ts`）
   - 同运动类型 + 规范化名称相同 → 判定重复，拦截并返回已有场地信息；
   - 名称不同但规范化地址相同 → 判定重复；
   - 坐标距离 < 80m 且名称含相同关键字 → 辅助提示（现有数据多为占位坐标，仅作弱匹配）。
   - 查重失败不会阻断正常录入。
2. **查重接口**（`venues.controller.ts`）
   - `POST /venues/check-duplicate`：传入 name/address/sportType，返回 `{ isDuplicate, duplicate }`；
   - `GET /venues/duplicates`：管理端用，返回疑似重复分组（同名 / 同地址）。
3. **批量导入脚本**：`src/add-venue-bulk.ts`（命令 `npm run add-venue:bulk`）
   - 内置 CSV 解析（支持双引号转义），全字段映射；
   - 入库前自动查重（库内同名 / 库内同地址 / 文件内重复）并跳过；
   - 字段校验（sportType、cityCode、坐标合法性）；
   - 支持 `--dry-run` 只出校验报告不写库。

### 前端（Next.js，`Web/webapp`）
1. **查重去重页**：`/admin/duplicates`
   - 按同名 / 同地址分组展示，可按篮球 / 足球筛选；
   - 每条可跳转编辑、删除（仅管理员），刷新重新拉取。
2. **添加页实时查重**：`/admin/add-venue`
   - 名称 / 地址输入防抖 600ms 自动比对，命中重复即红色提示已有场地；
   - 提交时后端再次拦截，重复不会写入。
3. **前端代理路由**：`src/app/api/venues/duplicates`、`src/app/api/venues/check-duplicate`。
4. **CSV 模板**：`data/venues-template.csv`。

## 二、运行与验证

- 本地后端：`cd Server/api && npm run dev`（端口 4000，连 `.env` 中的 `DATABASE_URL`）
- 本地前端：`cd Web/webapp && npm run dev`（端口 3000）
- 批量导入预览：`npm run add-venue:bulk -- <csv路径> --dry-run`
- 正式入库：去掉 `--dry-run`

> 注意：`.env.local` 的 `NEXT_PUBLIC_API_BASE` 当前指向线上 Railway。后端新接口需**重新部署后端**后，线上前端代理才能访问；本地联调可临时改为 `http://localhost:4000`。

### 采集方式
- 工具：`Server/api/src/collect-poi.ts`（`npx ts-node src/collect-poi.ts <cityCode> [basketball|football|both] [maxPages]`）。
- 数据源：高德 Web 服务 POI 文本搜索（`/v3/place/text`），按类别码 `080104` 篮球场馆、`080105` 足球场过滤；名称/地址二次正则剔除综合馆、学校、单位内部、教培机构。
- 坐标：POI 自带 GCJ-02 经纬度，无需再地理编码；电话、参考人均价、开放时间、评分、照片 URL 同步抓取（备查 JSON）。

### 导入前需人工复核的边界项
1. **泛名场地**约 10 条：名称仅"篮球场/篮球公园/足球公园/室外足球场"，多为公园或单位内无名露天场，部分无电话，建议确认是否保留。
2. **复合存疑**：个别 POI 归为足球但活动网标注篮球+足球（如晟铭体育同心里足球公园），导入前按实际项目复核。
3. **价格字段**：`priceDisplay` 为高德点评"参考人均"，非场地租金；`priceMin/priceMax` 留空，正式录入前可按场租口径替换。
4. **材质/室内外**：`floorType`、`indoor`、灯光/淋浴等设施字段 POI 未提供，暂留空。
